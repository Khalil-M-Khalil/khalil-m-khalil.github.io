# Khalil Khalil - Portfolio (V4)

A clean, three-page static portfolio built with modern HTML5, CSS3, and vanilla JavaScript (no build step, no external dependencies). Deployed on GitHub Pages.

## Site Structure
1. **`index.html` (Landing Page):**
   - Welcomes visitors with the multidisciplinary hook: *"I design brands people remember, and test the systems that protect them."*
   - Two large above-the-fold choice cards directing visitors to **Design** (`design.html`) or **Technical** (`technical.html`), each with direct links to its respective CV.
   - Includes a compact Courses & Career Guidance section, Contact section, and footer.

2. **`design.html` (Creative & Brand Identity):**
   - Brand identity showcases (Almira, WHY Z, Take Car Taxi).
   - Motion Graphics showcase (Zuhal Logo Animation, Movo Dynamic Motion, Radd App Demo, Evolution Reel).
   - Creative Services, Process steps, Data & Research numbers, About Me, Creative CV, and Contact.

3. **`technical.html` (Technology & Cybersecurity):**
   - Technical capabilities block (Full-Stack, Web Apps, Security Analysis, Workflow Automation).
   - Documented vulnerability research (Meta race condition, TikTok open redirect).
   - Recognition & rankings (OffSec highlight, Horizon Lab #1 in Syria / #177 worldwide, Favikon #1 in Syria).
   - Verified certifications (Secstein MSPT, Secstein IGH, IBM SkillsBuild, Cisco Networking).
   - Software and forensics tools (Phoenix, Nabra, Sada).
   - Client video endorsements and 10 verified humanitarian case proofs & takedown documentation.
   - Technical CV and Contact.

## Local Development
- Run locally: `python3 -m http.server`, then open `http://localhost:8000`
- Deployed on GitHub Pages via the `main` branch.
