# Khalil Khalil - Portfolio (V3)
Two pages: `index.html` (creative) and `technical.html` (technology and security). Each has its own CV in `assets/`.
- Run locally: `python3 -m http.server`, then open http://localhost:8000
- Deploy: upload the contents of this folder (not the folder itself) to the `Khalil-M-Khalil.github.io` repo, then Settings > Pages > main / root.
- Replace an image or CV by keeping the same file name inside `assets/`.
